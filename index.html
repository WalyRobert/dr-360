🌟 O que é o DR360°?

O DR360° é um player de vídeo imersivo em 360 graus que oferece uma experiência visual única para o Dodge Recian. Veja cada detalhe do seu veículo sob todos os ângulos.

💻 Como Usar

1. Clique no botão "START" - Abrirá o aplicativo em tela cheia

2. Use o mouse/tela tátil - Arraste para girar a câmera em 360°

3. Zoom - Use a roda do mouse ou pizza para aproximar/afastar

4. Modo VR - Se disponível, use seu dispositivo VR para imersão completa

5. Rastreamento de Cabeça - Com um headset VR, mova sua cabeça para controlar a visualização

✨ Recursos

• 360° Full View - Visualização completa do veículo em alta resolução

• Qualidade HD - Vídeos em alta definição para melhor experiência

• Compatibilidade VR - Funciona com óculos de realidade virtual

• Rastreamento de Cabeça - Controle intuitivo com movimento da cabeça
